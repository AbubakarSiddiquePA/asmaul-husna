# Al Asma Ul Husna

A responsive website for reading the 99 Names of Allah with Arabic text, transliteration, English and Malayalam meanings, and sourced reflections.

Live website: https://asmaul-husna-psi.vercel.app

## Local preview

Open `index.html` in a browser. Icons and the sharing image are included; Google Fonts require internet access. Visitor analytics run on the deployed Vercel site.

## Deployment

This is a static HTML project. In Vercel select Other for the framework, leave the build and install commands empty, and use `.` as the output directory. The production branch is `main`.

## Content

The page follows a common traditional enumeration. Scholars differ over the exact list; short translations are explanatory summaries. Source references and a correction contact are included on the page.
